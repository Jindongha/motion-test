# 쿠킹클래스 레시피 설계 (2026-08-17 사용자 확정안)

디자인 초안: claude.ai Design "쿠킹클래스 모션게임 서비스" — 계란말이 플로우 4화면 (수채화 일러스트 + 단계 진행바 + 모션/터치 배지 + 판정 게이지)

## 초보

**계란말이 (4단계)**: 휘젓기(계란 풀기) → 붓기·자이로(팬에 붓기) → 말기·터치(익은 부분부터) → 붓기+말기 반복(두께)
**팬케이크 (4단계)**: 체치기 → 휘젓기 → 붓기 → 뒤집기(기포 타이밍 판정)
**라면 (4단계)**: 불조절 → 붓기(면·스프) → 휘젓기 → 누르기(홀드 시간 = 익힘)
**돈까스 (5단계, 초보 보스)**: 누르기(고기 펴기) → 바르기×3(빵가루 옷) → 불조절(기름 온도) → 뒤집기 → 칼질(플레이팅)

## 중급

**계란샌드위치 (5)**: 불조절 → 으깨기(홀드+드래그) → 휘젓기 → 바르기 → 칼질(대각선)
**김치찌개 (5)**: 칼질 → 볶기 → 붓기 → 불조절(센불→중불 전환 판정) → 휘젓기
**김치볶음밥 (5)**: 칼질 → 볶기 → 불조절(센불 유지 판정) → 뒤집기(웍 토스) → 붓기+뒤집기(계란 프라이)
**해물파전 (5)**: 칼질 → 휘젓기 → 붓기 → 누르기 → 뒤집기(대형, 실패 판정 큼)
**크레페 (5)**: 체치기 → 휘젓기 → 붓기 → 바르기(원형 트레이싱, 핵심) → 뒤집기(타이트)
**야끼소바 (6)**: 칼질 → 볶기 → 붓기(면) → 붓기(소스) → 볶기+뒤집기 → 흔들기(토핑)
**알리오 올리오 (6)**: 칼질(두께 균일도) → 불조절(약불 유지, 핵심) → 볶기 → 붓기(면수) → 휘젓기(유화, 빠른 원) → 흔들기(코팅)

## 마스터

**볼로네제 (8)**: 칼질×3(미르푸아) → 으깨기 → 볶기(장시간) → 붓기 → 불조절(약불) → 휘젓기(장시간 저속, 지구력) → 불조절(면) → 휘젓기+흔들기
**마카롱 (8)**: 체치기×2 → 휘젓기 고속(머랭, 속도 유지) → 휘젓기 저속(마카로나주, 횟수 초과 즉시 실패) → 붓기(자이로 정밀) → 흔들기(기포) → 누르기(건조) → 불조절(오븐) → 바르기(필링)
**초밥 (7)**: 불조절 → 붓기+휘젓기 → 흔들기(부채질) → 칼질(각도·속도 3중 판정) → 누르기(강약 압력) → 바르기(와사비) → 누르기(마무리)
**만두 (8)**: 칼질 → 으깨기 → 휘젓기 → 누르기 → 말기(드래그 횟수=주름) → 붓기 → 불조절 → 뒤집기

## 기존 스파이크 대비 신규 판정 메커니즘

| 필요 판정 | 상태 |
|---|---|
| 휘젓기 속도 판정 (고속/저속, rev/s) | 미구현 — dAng/dt로 쉬움 |
| 불조절 유지 판정 (구간 유지 시간) | 미구현 — 다이얼 + 존 체류 시간 |
| 뒤집기 타이밍 판정 (기포/링 타이밍) | 미구현 — 리듬게임 판정창 문법 |
| 칼질 균일도 (간격·두께) | 미구현 — 스트로크 위치 분산 |
| 바르기 원형 트레이싱 | 미구현 — 커버리지+경로 |
| 누르기 압력(강약) | ⚠️ 웹 터치 압력 API 없음 — 홀드 길이/리듬으로 대체 설계 필요 |
| 단계 시퀀스 프레임워크 (스텝 체인) | 미구현 — 화면별 감지기를 순차 연결 |

이미 검증됨: 휘젓기 회전수, 붓기 기울기·유량, 말기 수직+저속 판정, 칼질 각도·직선도·속도, 볶기/체치기 왕복, 흔들기 지속, 홀드류.
