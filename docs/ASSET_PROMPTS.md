## 1. 붓기 단계 — 새 그림체로 통일 (지금 붓기는 옛날 회색 볼이라 휘젓기와 톤이 다름)

### A1. 빈 사각 팬 (배경용, 1장)
> [공통 문구] 계란말이용 **사각 프라이팬**. 구리색 또는 진한 갈색 몸체, 나무 손잡이가 오른쪽 위로 뻗어 있음. 팬 안은 **완전히 비어 있고** 바닥이 보임. 레퍼런스 시트의 '구워지는 계란' 팬과 같은 모양·같은 각도.

### A2. 팬 속 계란물 채움 4단계 (같은 팬, 4장 따로)
팬은 A1과 **픽셀 단위로 동일**해야 합니다. 매번 A1 결과물도 함께 첨부하고 이렇게 요청:
> [공통 문구] 첨부한 빈 팬 이미지를 **그대로 두고(위치·크기·각도·손잡이 전부 동일)** 팬 안에만 계란물을 그려줘. 단계: **①** 팬 바닥 가운데에 손바닥만 한 노란 계란물 웅덩이 하나 / **②** 팬 바닥의 절반 정도를 덮음 / **③** 거의 다 덮였고 가장자리만 바닥이 보임 / **④** 팬 가득 평평하게 차서 표면이 매끈함. 계란물 위에 부드러운 소용돌이 결 한두 줄. **물줄기·볼·거품기 등 다른 물체는 절대 그리지 말 것.**

(→ 제가 팬 안쪽만 오려서 오버레이로 씁니다. 물줄기는 코드로 그립니다.)

### A3. 기울여 붓는 볼 (스프라이트, 1장) ★ 중요
> [공통 문구] 레퍼런스 시트의 **크림색 볼(계란물이 든 볼)** 과 같은 볼을, 오른쪽으로 약 **35도 기울인 모습**. 볼 안의 노란 계란물이 기울어진 쪽 입술로 쏠려 있고 **입술 끝에서 막 넘치려는 순간**. **물줄기는 그리지 말 것** — 계란물이 볼 밖으로 나오지 않은 상태. 볼 전체가 잘리지 않게 여백 충분히.

(→ 지난번 회색 볼 스프라이트는 물줄기가 같이 그려져 있어서 회전하면 어긋났습니다. 이번엔 물줄기 없이.)

### A4. 쏟아진 계란물 (실패 연출용, 1장)
> [공통 문구] 바닥에 **쏟아져 퍼진 노란 계란물 웅덩이**. 가장자리가 울퉁불퉁하게 튄 모양, 작은 방울 몇 개가 주변에 흩어져 있음. 팬이나 볼 없이 **웅덩이만**.

## 2. 말기 단계 (현재는 아주 오래된 3컷 그림 — 전부 교체)

### B1. 팬 속 계란 시트 → 말리는 4단계 (같은 팬, 4장 따로)
A1 빈 팬을 첨부하고:
> [공통 문구] 첨부한 빈 팬을 **그대로 두고** 팬 안에만 계란을 그려줘. 단계: **①** 팬 가득 익은 노란 계란 시트가 평평하게 깔림 / **②** 시트의 오른쪽 끝이 한 번 접혀 말리기 시작 / **③** 절반이 통통한 롤로 말렸고 나머지 절반은 아직 평평 / **④** 완전히 말려서 통통한 계란말이 롤이 팬의 **왼쪽 끝**에 놓여 있고 나머지 바닥은 비어 있음. 롤의 단면 결이 살짝 보이게.

### B2. 뒤집개 (스프라이트, 1장) — 손가락 따라 움직일 도구
> [공통 문구] 나무 손잡이가 달린 **납작한 계란말이용 뒤집개(스패출러)** 하나. 레퍼런스의 거품기와 같은 톤. 손잡이가 위, 넓적한 날이 아래를 향하게 **세로로** 배치.

### B3. 2차 붓기 — 롤이 있는 팬에 계란물 채움 4단계 (같은 팬, 4장 따로)
B1-④(롤이 왼쪽에 있는 팬)를 첨부하고:
> [공통 문구] 첨부한 팬(왼쪽에 계란말이 롤)을 **그대로 두고**, 롤 오른쪽 빈 바닥에만 계란물을 그려줘. 단계: **①** 작은 웅덩이 / **②** 빈 바닥의 절반 / **③** 빈 바닥 거의 전부 / **④** 빈 바닥 가득, 롤 밑으로도 살짝 흘러 들어감. 롤은 절대 바꾸지 말 것.

### B4. 2차 말기 — 두꺼워진 롤 (B1과 같은 요령, 4장 따로)
> [공통 문구] 첨부한 팬을 그대로 두고: **①** 왼쪽 롤 + 오른쪽에 익은 계란 시트 / **②** 롤이 시트를 감기 시작 / **③** 절반 감음 / **④** 처음보다 **두 배 두꺼워진** 롤이 팬 가운데에 놓임.

## 3. 완성 · 도감 · 실패

### C1. 완성 계란말이 접시 (완성 화면 + 도감, 1장)
> [공통 문구] 둥근 **흰 접시 위에 계란말이 5조각**이 비스듬히 줄지어 놓임. 단면의 소용돌이 결이 선명하고 노란색에 살짝 갈색 구운 자국. 접시 한쪽에 케첩 한 방울(선택).

### C2. 요리 썸네일 (도감·목록용, 1장)
> [공통 문구] C1과 같은 계란말이 접시를 **정사각형 안에 꽉 차게** 약간 더 위에서 본 구도로. 아이콘처럼 단순하고 또렷하게.

### C3. 실패 결과물 — 도감 수집품 (각 1장)
실패도 수집품으로 모으는 컨셉이라 귀엽고 웃기게:
> [공통 문구] **탄 계란말이**: 겉이 거뭇하게 탔고 연기 두 줄이 올라오는 계란말이 한 덩이. 표정 없이 물체만.
> [공통 문구] **터진 계란말이**: 말다가 풀려서 너덜너덜해진 계란 시트 덩어리.
> [공통 문구] **쏟은 계란말이**: 팬 옆 바닥에 엎어진 계란물 웅덩이와 작은 롤 조각 (A4와 비슷하지만 롤 조각 포함).
