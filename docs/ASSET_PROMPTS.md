3단계: 롤이 시트를 절반 감으며 팬 정중앙까지 옴. 롤은 눈에 띄게 두껍고 단면에 소용돌이 결이 두 겹. 오른쪽 바닥에 시트 절반 남음. 시트 익은 정도 3.
4단계: 롤이 시트를 전부 감고 팬 오른쪽 끝(손잡이 쪽)에 도착. 처음보다 두 배 두꺼운 롤 하나가 오른쪽 끝에 놓여 있고, 왼쪽 바닥은 비어 있음. 단면에 소용돌이 결 여러 겹, 겉면 익은 정도 4.
```

### 7-B. 한 장에 2×2 격자
```
첨부한 빈 팬 이미지를 기준으로, 한 번 말아둔 계란말이 롤이 새 시트를 감으며 두꺼워지는 "두 번째 말기" 4단계를 한 장의 이미지 안에 2×2 격자로 그려줘. 순서는 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래. 네 칸은 크기가 완전히 같고 칸 사이는 흰색 여백으로만 구분. 각 칸의 팬은 칸 가운데에 같은 크기로.

절대 규칙:
- 네 칸 모두 팬은 첨부한 빈 팬과 완전히 동일. 팬 안쪽 내용물만 달라짐.
- 그림체는 레퍼런스와 동일: 두꺼운 진한 갈색 외곽선, 파스텔 톤, 부드러운 셀 셰이딩.
- 방향: 팬 손잡이는 오른쪽 위. 롤은 "왼쪽 끝(손잡이 반대편)"에서 출발해 "오른쪽 끝(손잡이 쪽)"으로 굴러가며 시트를 감음. 네 칸 모두 같은 방향.
- 롤은 단계마다 두꺼워지고 단면에 소용돌이 결이 겹겹이. 롤 겉면 익은 정도 4. 새 시트는 익은 정도 2→3.
- 배경은 순수한 흰색. 글자, 숫자, 라벨, 칸 번호, 격자선, 뒤집개, 젓가락, 손, 물줄기, 볼 등 다른 물체 절대 금지.

왼쪽 위(1단계): 왼쪽 끝에 통통한 롤(익은 정도 4), 오른쪽 바닥 전체에 새 시트가 평평하게 깔려 왼쪽 끝이 롤에 붙어 있음. 시트 익은 정도 2.
오른쪽 위(2단계): 롤이 오른쪽으로 한 바퀴 굴러 시트를 감기 시작. 롤은 팬 왼쪽 1/3 지점, 조금 두꺼워짐. 오른쪽에 시트 남음. 시트 익은 정도 3.
왼쪽 아래(3단계): 롤이 시트를 절반 감고 정중앙. 눈에 띄게 두껍고 단면 결 두 겹. 오른쪽에 시트 절반 남음.
오른쪽 아래(4단계): 롤이 전부 감고 오른쪽 끝 도착. 두 배 두꺼운 롤, 왼쪽 바닥 비어 있음. 단면 결 여러 겹, 겉면 익은 정도 4.
```

## 8. `spatula` — 뒤집개 (손가락 따라 움직일 도구)
첨부: REF
```

## 11. `fail-burnt` / `fail-torn` / `fail-spill` — 실패 수집품 3종 (한 프롬프트, 3장 따로)
첨부: REF
```
첨부한 레퍼런스 이미지와 완전히 동일한 그림체로, 요리에 실패한 결과물 3가지를 각각 따로 이미지 3장으로 생성해줘. 두꺼운 진한 갈색 외곽선, 파스텔 톤, 부드러운 셀 셰이딩, 귀여운 한국 모바일 게임 일러스트 느낌. 카메라는 살짝 위에서 내려다본 3/4 시점. 셋 다 귀엽고 웃기게, 하지만 얼굴이나 표정은 절대 그리지 말 것.

공통 규칙: 배경은 순수한 흰색(#FFFFFF) 단색. 글자, 숫자, 라벨, 워터마크 없음. 물체가 잘리지 않게 사방 10% 이상 여백, 정중앙 배치. 팬, 접시, 손, 바닥 무늬 등 다른 물체는 넣지 말 것.

1장째 (탄 계란말이): 겉이 거뭇하게 탄 계란말이 롤 한 덩이. 노란색은 거의 안 보이고 진갈색과 검은 탄 자국이 얼룩덜룩. 위로 회색 연기 두 줄이 구불구불 올라감.
2장째 (터진 계란말이): 말다가 풀려서 너덜너덜해진 노란 계란 시트 덩어리. 반쯤 말리다 만 부분과 찢어진 조각들이 뒤엉켜 있음.
3장째 (쏟은 계란말이): 바닥에 엎어진 노란 계란물 웅덩이와 그 위에 떨어진 작은 계란말이 롤 조각 두어 개. 웅덩이 가장자리는 울퉁불퉁하고 주변에 방울이 튀어 있음.
```

## 받은 뒤 버릴 기준 (하나라도 걸리면 같은 프롬프트로 다시)

- 배경이 흰색이 아니라 크림색/회색
- 글자·숫자·칸 번호가 어디든 들어감
- 물체가 가장자리에서 잘림
- 세트(5·6·7): 팬이 첨부한 것과 위치·크기·각도가 달라짐 — 겹쳐 보면 바로 보임
- 세트(5·7): **말리는 방향이 단계 사이에서 바뀜** (5는 오른쪽→왼쪽, 7은 왼쪽→오른쪽이어야 함)
- 세트: 익은 정도가 단계를 거꾸로 감 (뒤 단계가 더 연한 색)
- 3번 볼에 물줄기가 그려짐 / 8번 뒤집개에 손이 그려짐

같은 프롬프트를 2~3번 돌려 제일 일관된 세트를 고르는 게 빠릅니다.
