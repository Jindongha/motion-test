# 쿠킹클래스 — 동작 테스트

요리 미니앱 "쿠킹클래스"용 제스처/센서 스파이크. 소중리듬과 완전 별개 프로젝트.

- `index.html` — 단일 파일 테스트 앱. 13종 요리 동작을 각각 전용 화면에서 테스트
- `serve.bat` — 더블클릭으로 로컬 서버 실행 → `http://localhost:8123/?sim`

## 동작 목록

| 동작 | 방식 | 감지 |
|---|---|---|
| 볶기 | 모션 | 수평 직선 왕복 (원형성 낮음) |
| 뒤집기 | 모션 | 위 방향 수직 스파이크 |
| 칼질하기 | 터치 | 세로 직선 스트로크 (비스듬·곡선 거부) |
| 불조절 | 터치 | 노브 회전 다이얼 (0~270°) |
| 붓기 | 기울기 | 중력 기준 기울기 45°+ 에서 유량 |
| 휘젓기 | 모션+터치 | 수평 원형 회전 (원형성 높음) / 원 드래그 |
| 바르기 | 터치 | 캔버스 커버리지 95%+ |
| 흔들기 | 모션 | 흔드는 동안 0.2초당 +1 (지속 시간 기반) |
| 누르기 | 터치 | 1.5초 홀드 |
| 체치기 | 모션 | 수평 직선 왕복 (볶기와 동일 감지기, 화면 분리) |
| 말기 | 모션+터치 | 수직(90°)·저속 스트로크만 성공 — 각도 초과/과속은 실패 집계. 허용각·속도 슬라이더 공유 |
| 으깨기 | 터치 | 2초 홀드 |
| 갈기 | 모션 | 사방팔방 흔들기, 가속 피크 하나당 1회 |

## 테스트 방법

- **데스크톱**: `serve.bat` → `http://localhost:8123/?sim` — 하단 SIM 버튼으로 모션 합성 신호 주입, 터치 동작은 마우스로
- **폰**: HTTPS 필수. GitHub Pages 배포 후 접속 → "센서 켜기"로 iOS 권한 팝업 확인(토스 WebView go/no-go 포인트)
- 각 화면의 민감도 슬라이더로 현장 튜닝, 홈의 기록/복사로 원시 센서 데이터(JSON) 추출 가능

## 설계 메모

실제 게임처럼 **한 화면 = 한 제스처**. 같은 모션(흔들기/체치기)도 화면이 다르면 충돌하지 않음.
감지는 중력 기준 좌표계(수직/수평 분해 + 수평 방향각 원형성)라 폰을 쥔 자세와 무관.
iOS 가속도 부호 반전 자동 처리, 센서 시작 직후 0.35초 워밍업.
